# Practice Exam Sources

## Free

| Source | What | Link |
|---|---|---|
| OpenExamPrep — B-1/B-2/KB-1/KB-2 | 100+ practice questions, no signup | https://open-exam-prep.com/practice/us-azroc-b1-b2-residential-commercial |
| OpenExamPrep — AZ GC study guide | 14-chapter free guide organized by blueprint | https://open-exam-prep.com/study-guides/az-general-contractor |
| AZ ROC Applicant Education Seminar | Monthly, application process | https://azroc.gov/applying-for-a-license |

> Caution: some free sites still list outdated info (for example the old "Business Management" exam, since replaced by the SRE, or claims that NASCLA isn't accepted). Trust PSI and AZ ROC first.
